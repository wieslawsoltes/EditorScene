# EditorScene

Independent, reusable code-editor components for Uno Platform desktop and WebAssembly, with Actipro SyntaxEditor's documented capabilities as the functional target.

This repository is under active implementation. Full Actipro API, language-service, visual, and behavior parity is **not yet claimed**. No proprietary Actipro implementation or assets are included.

The text engine and native Uno editor build on the MIT-licensed UnoEdit port at `wieslawsoltes/AvaloniaEdit`, pinned to commit `1a2df473f157a0127d2559f241dc712d1ce60188`. Its original authorship and license are retained. New EditorScene packages provide an independent public API and controls.

Implementation, browser validation, packaging, and GitHub Pages publishing are being established in this repository.
