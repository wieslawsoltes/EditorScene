# EditorScene

Independent code-editor components for Uno Platform desktop and WebAssembly.
Actipro SyntaxEditor's documented behavior is the compatibility target, not a
claim of completed parity. No proprietary Actipro implementation or assets are
included. See `docs/compatibility.md` for the tested scope and remaining gaps.

Clone with `git clone --recurse-submodules https://github.com/wieslawsoltes/EditorScene.git`.
The MIT-licensed UnoEdit dependency is pinned, not taken from a moving branch.
